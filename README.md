# 🚀 Terkoiz.Skipper (RU Localization & SPT 5.0 Port)

Модификация для **SPT (Single Player Tarkov)**, которая добавляет удобную кнопку **«ПРОПУСТИТЬ»** в окно заданий. Больше не нужно искать редкие предметы или бегать по карте, если вы застряли на каком-то этапе квеста — просто нажмите кнопку и завершите цель!

Данная версия адаптирована под **SPT 5.0.0** (EFT 1.1.5.1) и включает в себя полную русскую локализацию меню настроек.

## ✨ Особенности

* **Пропуск любых целей:** Работает как для сюжетных (основных), так и для побочных квестов.
* **Безопасное завершение:** Мод использует нативные методы игры (`QuestController`) для корректного завершения цели, что предотвращает поломку сохранений.
* **Умное отображение:** Кнопка скрывается автоматически, если цель квеста уже выполнена.
* **Русская локализация:** Меню настроек (F12) и всплывающие окна подтверждения полностью переведены на русский язык.
* **Гибкая настройка:** Вы можете настроить отображение кнопок по удержанию горячей клавиши или сделать их видимыми постоянно.

## 📦 Установка

1. Убедитесь, что у вас установлен **SPT 5.0.0**.
2. Скачайте последний релиз мода (файл `.zip`).
3. Распакуйте содержимое архива в корневую папку вашей игры.
   * Путь должен получиться таким: `[Ваша папка с игрой]\BepInEx\plugins\terkoiz-skipper\`
4. Запустите игру. Если в консоли BepInEx появилась строка `[Skipper] Перевод выполнил zzzNIKOzzz`, значит мод успешно загружен.

## ⚙️ Настройки (Меню F12)

Настройки мода находятся во вкладке **«Основное»** (Main):

* **1. Включено** — Глобальный переключатель мода (вкл/выкл).
* **2. Всегда показывать кнопку пропуска** — Если включено, кнопки видны всегда. Если выключено, кнопки появляются только при зажатии горячей клавиши.
* **3. Клавиша показа** — Горячая клавиша для отображения кнопок (по умолчанию — `LeftControl`).
